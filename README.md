# Adda24 (আড্ডা24) - Restaurant & Café Website

Modern, responsive web application for **Adda24**, a trendy and pocket-friendly café in Malda, West Bengal.

## 🚀 Features

- **Branded Design**: Clean, vibrant aesthetic with authentic Adda24 branding and logo.
- **Dynamic Menu & Filters**: Categorized menu with instant search for dishes, dietary indicators, and real-time order selection tray.
- **Direct Ordering Modal**: Seamless options to call directly, place orders via WhatsApp with formatted dish lists, or order on Swiggy/Zomato.
- **Interactive AI Chat Assistant**: Answers queries about dishes, prices, delivery, timings, location, and recommendations.
- **Full Contact & Map Integration**: One-click Google Maps directions and direct dialer.

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/sultan0990/Adda24-demo.git

# Navigate to project folder
cd Adda24-demo

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
